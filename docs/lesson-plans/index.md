# Lesson Plans

Two classroom-ready plans per lab, each built for a **single 45–50 minute
period** and tested against what the app actually does.

| Lab | Plan | Grade band |
|---|---|---|
| 🧪 Chemistry | [Conditions Change Everything](chemistry-01-conditions.html) | 6–9 |
| 🧪 Chemistry | [Auditing the Machine](chemistry-02-confidence.html) | 9–12 |
| 🌿 Ecosystem | [The Wolf and the River](ecosystem-01-trophic-cascade.html) | 5–9 |
| 🌿 Ecosystem | [Two Degrees](ecosystem-02-climate.html) | 8–12 |
| 🪐 Planets | [Finding Goldilocks](planets-01-habitable-zone.html) | 5–8 |
| 🪐 Planets | [Twin Worlds, Different Fates](planets-02-venus.html) | 9–12 |
| 🔬 Physics | [You Can't Climb Higher Than You Started](physics-01-energy.html) | 7–10 |
| 🔬 Physics | [The Experiment That Broke Classical Physics](physics-02-photoelectric.html) | 10–12 |

**Every plan uses the same spine:** predict → run → explain the gap. The gap
between what students expected and what happened is where the learning is; the
app just makes that gap fast, visual, and repeatable.

**Turn on 🎯 Challenge mode** in every one of these. It's the toggle that makes
the pedagogy work.
